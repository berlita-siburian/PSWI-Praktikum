Fungsi dari HTML (Hypertext Markup Language), CSS (Cascading Style Sheets), Javascript(Js), Gitbash

1.HTML (Hypertext Markup Language)
HTML berfungsi sebagai  pondasi atau kerangka dari sebuah bahasa pemogramanan untuk membuat sebuah website, HTML akan membuat judul, paragraf, gambar, dan masih banyak lagi tapi dalam bentuk polos.

2.CSS (Cascading Style Sheets)
CSS berfungsi sebagai bahasa yang digunakan untuk menampilkan style atau gaya pada website, yang dimana ketika sudah terdapat kerangkanya dari html akan dilanjut ke css untuk membuat warna, gaya atau dekorasinya

3.Js (javascript)
JS atau JavaScript adalah bahasa pemrograman tingkat tinggi yang berfungsi untuk membuat halaman website kita menjadi memiliki sebuah animasi atau menjadi interaktif

4.Gitbash
GIT adalah sistem pengontrol versi yang berfungsi menyimpan perubahan yang ada dan juga bisa memulihkan kode jika terjadi kesalahan atau bug. GIT juga berhubungan dengan platform seperti GITHub untuk berbagi dan mengelola project secara online.
